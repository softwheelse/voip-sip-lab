# Softwheelse VoIP & SIP Lab

A practical lab focused on learning, testing, and documenting VoIP and SIP technologies.

## About the Project

This repository documents experiments and configurations related to modern telecommunications systems.

Current areas of study include:

- SIP (Session Initiation Protocol)
- VoIP infrastructure
- Asterisk
- FreePBX
- SIP trunk configuration
- Call routing and dial plans
- Network and SIP troubleshooting

## Project Goals

The goal of this lab is to build a better understanding of how VoIP systems work, from SIP registration and trunk configuration to call routing and PBX administration.

## Technologies

- Asterisk
- FreePBX
- SIP
- Linux
- VoIP

## Status

This project is currently under development. Documentation and configuration examples will be added as the lab progresses.

## Security

No production credentials, SIP passwords, API keys, phone numbers, or other sensitive information are stored in this repository.
